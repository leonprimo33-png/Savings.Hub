# Savings.Hub

Sitio web de práctica para una tienda de tecnología, accesorios y perfumes.

## Archivos
- `index.html`: página de inicio con carrusel Bootstrap.
- `tienda.html`: catálogo de ocho productos con filtro por categoría.
- `servicios.html`: información de servicios.
- `nosotros.html`: historia, misión, visión, valores y equipo.
- `contacto.html`: formulario con validación nativa y envío del mensaje preparado a WhatsApp.
- `css/styles.css`: estilos propios, variables CSS, Flexbox, Grid y Media Queries.
- `js/main.js`: filtro de productos y funcionamiento del formulario.

## Cómo abrirlo
1. Descomprimí la carpeta.
2. Abrí la carpeta `savings_hub` en Visual Studio Code.
3. Abrí `index.html` en un navegador. También podés usar la extensión Live Server.

## Publicar gratis con GitHub Pages
1. Creá una cuenta en GitHub si todavía no tenés.
2. Creá un repositorio público llamado `savings-hub`.
3. Subí todos los archivos y carpetas, conservando la estructura.
4. En el repositorio, entrá a **Settings → Pages**.
5. En **Build and deployment**, elegí **Deploy from a branch**.
6. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
7. Esperá a que GitHub Pages publique el sitio. La URL aparecerá en la misma sección de Pages.

## Notas
- Bootstrap se carga desde su CDN, por lo que requiere conexión a internet.
- Las imágenes de ejemplo se cargan desde Unsplash y requieren conexión a internet.
- Los nombres de productos y el catálogo son demostrativos; consultar precios y stock.
- El formulario valida los campos en el navegador y prepara un mensaje para WhatsApp. No guarda datos en una base de datos ni envía correos.
- Revisá que el número de WhatsApp esté bien escrito antes de publicar.
